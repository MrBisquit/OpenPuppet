# Getting Started

<small>
    If you're looking for the plugin developer guide, <a href="systems/plugins/create.html">try here instead</a>.
</small>

To get started with OpenPuppet, you must first download the latest stable build from the GitHub repository.

<div class="other-actions">
    <a href="https://github.com/Project-Axion/OpenPuppet/releases/latest/" class="btn-primary-other">Download latest</a>
    <a href="https://github.com/Project-Axion/OpenPuppet/releases/" class="btn-outline-other">Releases</a>
</div>
<br />

Once you have it downloaded, run the installer to get it installed on your computer. Then launch it. Now you have the
application installed, follow the [OpenPuppet basics guide](/guides/basics/index.md).
