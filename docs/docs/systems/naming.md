# Naming conventions

## Command naming convention

A command has 2 parts: The source (the ID of the plugin source, i.e. the one that registered it),
and the command ID (typically a string of what look like random numbers and letters), separated
by an exclamation mark (`!`).

For example: `com.openpuppet.core!Jc7agK9dxLXbeNXUJM7BZFghJq0007pc`.
